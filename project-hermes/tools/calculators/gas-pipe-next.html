Gas Pipe Sizing
Schedule 40 · low pressure · IFGC longest length

Sizes each section of a low-pressure Schedule 40 gas system from the IFGC capacity tables, using the longest length method: one length for the whole system, and each section sized for the appliances it feeds.

Gas

Appliances

Input rating from each appliance's rating plate. All are assumed to run at once (402.2).

Longest length

Fittings on that run optional

With four or more fittings, their equivalent length (Table A102.2, screwed) is added to the run. Four elbows can be enough to move to the next row.

Sections

Split the piping at each tee. For each section, tap the appliances downstream of it.

Notes

CSST and other listed piping systems are sized from the manufacturer's own tables (402.3(2)); each brand differs. Above 2,000 ft elevation, the flow must be adjusted for altitude (402.2). Supply pressure at every appliance must meet its minimum (402.6).
